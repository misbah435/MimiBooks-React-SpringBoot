\# 📚 MimiBooks – Full-Stack Online Bookstore



A responsive online bookstore built using \*\*React, Spring Boot, and MySQL\*\*. MimiBooks allows users to explore books, search by title or author, manage a shopping cart, register, log in, and experience a simulated checkout process.



\## ✨ Features



\- \*\*Book Catalogue:\*\* Browse books with titles, authors, prices, categories, and cover images.

\- \*\*Search \& Filter:\*\* Search books and filter by category.

\- \*\*Shopping Cart:\*\* Add books, update quantities, and view the total.

\- \*\*User Authentication:\*\* Register and log in using email and password.

\- \*\*Demo Checkout:\*\* Choose UPI or card and simulate successful or failed payments.

\- \*\*Responsive Design:\*\* Designed to work across desktop and mobile screens.

\- \*\*MySQL Database:\*\* Store user information and book records.
